# Streamify

Streamify is a video-sharing platform built using the MERN stack. It includes features such as user authentication, video uploads, playlists, likes, comments, tweets, channel subscriptions, and watch history.

The project focuses on learning backend development concepts by building real-world features and RESTful APIs.
